### 🧭 About Me

- 🏢 I work at **Eternal Enterprise Technologies**, building and maintaining custom **Frappe / ERPNext** apps for clients across manufacturing, jewelry, textile, real estate, and e-commerce.
- 🛠️ Deep hands-on experience with **DocTypes, Server Scripts, Client Scripts, Print Formats (Jinja2 + ZPL), Script Reports, hooks, and bench CLI**.
- 🌐 Also build full-stack apps and frontends with **Vue.js, Next.js, and Python**, including e-commerce integrations (WooCommerce, Razorpay, Digio) and landing pages.
- 🤖 Exploring **AI & automation** — LLM-powered workflows, WhatsApp chatbots, n8n agents, and AI-assisted coding tools.
- 📍 Based in Ajmer, Rajasthan, India.
- 🎯 Currently focused on production support, integrations, and shipping polished client deliverables.
